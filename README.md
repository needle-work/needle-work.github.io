# Supplementary website

This folder contains a static research supplementary website. Open `index.html` in a browser or serve this folder locally with:

```sh
python3 -m http.server 8765
```

`index.html` contains the page content. `style.css` defines its layout and typography. `app.js` connects the interactive controls to the charts and media; `charts.js` provides the SVG chart components. `assets/data/` contains chart data, while `assets/figures/` and `assets/media/` contain the visual assets used by the page.
